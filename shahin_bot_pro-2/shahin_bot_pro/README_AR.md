# بوت الشاهين — النسخة المتقدمة

مشروع Python عربي كبداية قابلة للتوسعة: تسجيل أعضاء، أسماء مستعارة، قبول يدوي أو تلقائي، دعم فني، سجل تدقيق، إحصائيات، ولوحة ويب محلية محمية بكلمة مرور.

## تنبيه مهم قبل التشغيل
- القبول التلقائي في هذه النسخة يعتمد فقط على أن الاسم ضمن الطول المحدد. هذا ليس تحققاً من الهوية، لذلك اترك `AUTO_APPROVE=false` إذا كنت تحتاج مراجعة فعلية.
- لوحة الويب محلية افتراضياً على `127.0.0.1`. لا تعرضها للإنترنت مباشرة. الوصول الخارجي يحتاج HTTPS ومصادقة أقوى وإعداد خادم مناسب.
- لا تضع توكن البوت أو كلمة المرور في محادثات عامة.
- في هذه النسخة، رابط المجموعة يُرسل بعد القبول إن أضفت `TARGET_GROUP_LINK`. لم يتم تنفيذ إدخال العضو للمجموعة تلقائياً؛ تيليغرام يتطلب رابط دعوة/صلاحيات مناسبة، وسنضيف هذا الجزء بعد اختبار إعدادات مجموعتك.
- الرسائل العامة داخل المجموعة بالاسم المستعار ليست مفعلة كإرسال للمجموعة في هذه النسخة الأولية؛ البنية تجهز الاسم المستعار والتسجيل، ويجب إضافة أمر نشر مقيّد بالمجموعة قبل الاستخدام الفعلي.
- SQLite مناسب للتجربة على جهاز واحد، لكنه ليس مثالياً لتشغيل متعدد العمليات أو استضافة كبيرة.

## 1) المتطلبات
- Python 3.10 أو أحدث.
- تطبيق Python على الهاتف يدعم تثبيت الحزم وتشغيل ملفات متعددة، أو Termux على Android.
- اتصال إنترنت.

## 2) إعداد الملفات
1. فك ضغط ملف ZIP في مجلد جديد.
2. انسخ `.env.example` وسمّ النسخة `.env`.
3. افتح `.env` وعدّل:
   - `BOT_TOKEN`: توكن البوت من BotFather.
   - `ADMIN_IDS`: آيدي حساب المدير الرقمي.
   - `WEB_PASSWORD`: كلمة مرور طويلة.
   - `TARGET_GROUP_LINK`: رابط المجموعة إن أردت إرساله للمقبولين.
4. اترك `AUTO_APPROVE=false` في البداية.

## 3) تثبيت الحزم
من داخل مجلد المشروع نفّذ:

```bash
python -m pip install -r requirements.txt
```

إذا لم يدعم تطبيق الهاتف `pip` أو الملفات متعددة المجلدات، استخدم Termux أو بيئة Python موثوقة.

## 4) تشغيل البوت
```bash
python main.py
```

أرسل `/start` للبوت. المدير يستخدم `/admin`. لعرض عنوان لوحة الويب أرسل `/web`.

## 5) لوحة الويب
افتح من متصفح الهاتف على الجهاز نفسه:
`http://127.0.0.1:8080`

أدخل قيمة `WEB_PASSWORD`. إذا لم تعمل اللوحة، تأكد أن البوت ما زال يعمل وأن المنفذ 8080 غير مستخدم.

## 6) الاختبارات
من مجلد المشروع:
```bash
python -m unittest discover -s tests -v
```

## الأوامر
- `/start` بدء الاستخدام.
- `/menu` العودة للقائمة.
- `/admin` لوحة الإدارة (للمدراء فقط).
- `/web` عرض عنوان لوحة الويب.
- `/reply USER_ID نص الرد` يرسل رد دعم من المدير.

## حدود النسخة الحالية
هذه نسخة أساس قابلة للتشغيل والاختبار وليست بعد نظام إنتاج نهائي. قبل استخدامها لمجموعة حقيقية، ينبغي اختبار تدفق التسجيل والقبول، وإضافة إرسال الرسائل العامة بالاسم المستعار وإدارة دعوات تيليغرام فعلياً، وتوسيع المصادقة للوحة الويب، واختبارها على نسخة Python في هاتفك.
