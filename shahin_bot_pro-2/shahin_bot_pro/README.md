# بوت الأسماء المستعارة للمجموعات والقنوات

بوت تيليجرام لإدارة مجموعة أو قناة بأسماء مستعارة. الأعضاء يكتبون في الخاص، والبوت ينشر بالاسم المستعار بعد موافقة المدير.

## المتطلبات

- Python 3.10+
- البوت مشرف في المجموعة أو القناة مع صلاحية النشر وحذف الرسائل ودعوة الأعضاء

## التثبيت والتشغيل

```bash
# تثبيت المتطلبات
pip install --break-system-packages -r requirements.txt

# تشغيل البوت مع اللوحة
python main.py
```

الحذف التلقائي للمحادثات يعمل كل 24 ساعة بعد ربط المجموعة (`AUTO_PURGE_ENABLED=true`).

للنشر على Render المجاني راجع قسم Render في `DEPLOY.md`.

يمكن تعيين المتغيرات التالية اختيارياً:

```bash
export BOT_TOKEN="your-bot-token"
export ADMIN_ID="1441524960"
export DB_PATH="/path/to/alias_group.db"
```

للنشر على سيرفر مجاني (Oracle Cloud أو Docker) راجع `DEPLOY.md`.

## التسجيل ورابط الدخول

شارك رابط البوت فقط، وليس رابط المجموعة.

1. الشخص يفتح البوت في الخاص ويرسل `/start`
2. يرسل الاسم الحقيقي ثم الاسم المستعار
3. يصل طلب الموافقة للمدير مع زرّي قبول/رفض
4. بعد القبول يرسل البوت له في الخاص رابط دخول لمرة واحدة
5. الكتابة الافتراضية عبر الخاص مع البوت حتى تظهر بالاسم المستعار دون كشف الهوية
6. من أراد الكتابة داخل المجموعة على مسؤوليته يرسل `/ingroup` ويؤكد التحذير. إشعار «يكتب» سيظهر باسمه الحقيقي ثم تُعاد الرسالة بالاسم المستعار. الإلغاء عبر `/outgroup`
7. غير المقبولين يُطردون إذا دخلوا المجموعة أو تُرفض طلبات انضمامهم للقناة

المدير يربط الوجهة مرة واحدة:

- المجموعة: `/setgroup` داخلها
- القناة: الأوامر داخل القناة لا تصل للبوت. اربطها من الخاص عبر `/setchannel`:
  - حوّل أي منشور من القناة إلى البوت
  - أو `/setchannel -100xxxxxxxxxx`
  - أو `/setchannel @username`
  - أو انشر رمز `BIND-XXXX` الذي يعطيك البوت مرة واحدة في القناة

يجب أن يكون البوت مشرفاً مع صلاحية دعوة الأعضاء. في القناة عطّل التعليقات حتى لا تُكشف الهوية.

- `/invite <id>` يعيد إرسال رابط الدخول لعضو مقبول

## الأسماء الظاهرة

- المدير يظهر باسم `المدير`
- المشرفون يظهرون `مشرف 1` ثم `مشرف 2` وهكذا
- بقية الأعضاء يظهرون بالاسم المستعار الذي اختاروه

## كشف الهوية

يظهر زر `⚡` بجانب كل رسالة معاد نشرها. المدير يضغطه فتصل هوية صاحب الرسالة في الخاص فقط.

يمكن أيضاً الرد على الرسالة ثم إرسال `*`. المشرف لا يكشف إلا بعد `/allowreveal`.

يجب أن يكون المدير قد راسل البوت في الخاص عبر `/start` حتى تصله التفاصيل.

## القوانين

أرسل `/rules` لعرض القوانين. المدير يعدّلها عبر `/setrules` متبوعاً بالنص أو بالرد على رسالة.

## أوامر الإدارة

أوامر الأعضاء:

- `/ingroup` تفعيل الكتابة داخل المجموعة على مسؤولية العضو بعد تأكيد
- `/outgroup` إلغاء الكتابة داخل المجموعة والعودة للخاص فقط

كل أوامر التيليجرام بالإنجليزية حتى تظهر في قائمة البوت وتعمل على Python 3.

- `/setgroup` داخل المجموعة لربطها
- `/setchannel` ربط قناة من الخاص (تحويل منشور / معرّف / رمز BIND)
- `/invite <id>` إعادة إرسال رابط الدخول
- `/purge` مسح المحادثات الحديثة لتعود فارغة
- `/lockgroup` قفل الدخول إلا عبر رابط البوت أو المدير
- `/pending` طلبات الانتظار
- `/approve <id>` قبول
- `/reject <id>` رفض
- `/ban <id>` حظر (مدير فقط)
- `/unban <id>` رفع الحظر
- `/setmod <id>` تعيين مشرف
- `/unsetmod <id>` إلغاء الإشراف
- `/allowreveal <id>` السماح لمشرف بالكشف
- `/denyreveal <id>` منع الكشف
- `/members` قائمة الأعضاء
- `/stats` الإحصاءات
- `/whois <id>` عرض هوية عضو
- `/announce <text>` إعلان في المجموعة أو القناة (مدير فقط)
- `/wipe` مسح كل البيانات بعد تأكيد بزرّين (مدير فقط)

إيقاف وتشغيل البوت (مدير فقط):

- `/pause` إيقاف إعادة النشر مؤقتاً
- `/resume` استئناف إعادة النشر
- `/control` لوحة بأزرار الإيقاف وإعادة التشغيل وإيقاف العملية
- `/restart` إعادة تشغيل عملية البوت بعد تأكيد
- `/stop` إيقاف عملية البوت بعد تأكيد

كتم بالرد على رسالة البوت ثم:

- `/mute 10min`
- `/unmute`
